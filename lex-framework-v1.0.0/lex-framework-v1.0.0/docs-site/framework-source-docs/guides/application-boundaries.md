# REST, media and output boundaries

APIView is the transport-neutral handler contract. RouteTable and RestRuntimeBuilder bind authentication, tenant resolution, permissions, middleware, idempotency and throttling; AxumAdapter handles HTTP. Configure CORS, body/header/URI limits and security headers before deployment. JSON parsing requires application/json or an application/*+json media type. Invalid content type is 415; malformed JSON is 400. The adapter defaults to insecure transport; explicitly mark a listener secure only when its TLS/trusted ingress boundary is real.

Lex exposes IdempotencyStore and DistributedThrottleStore traits; the HTTP tests provide process-local fixtures, not production providers. Supply a durable, atomic backend appropriate to your deployment. Idempotency keys are store-global: another user or tenant reusing a key gets a conflict, not a replay. Fingerprints bind method, route, principal, tenant and exact body bytes; differently encoded equivalent JSON is a different request. Concurrent in-progress retries return 409 with Retry-After. Expiry permits a new mutation. If persisting a response fails after the mutation commits, Lex cannot guarantee exactly-once effects; coordinate application persistence and the store before making that promise. WebSocket support is available through Axum but complete live framing, proxy and browser interoperability coverage remains experimental.

MemoryStorage is temporary. FileSystemStorage confines relative operations through a directory capability, rejects unsafe key components and uses unique temporary upload files with atomic replacement. Upload policy must enforce application limits and file types. S3 configuration exists but the runtime provider remains incomplete. A disabled NoopScanner returns Clean without scanning; that result is not a malware safety certification. ClamAV transport uses bounded NUL-terminated responses, rejects malformed/provider errors and is limited by a timeout. Production acceptance must decide whether scanner failures reject uploads (recommended) rather than silently treating failures as clean.

Sanitization is context-specific. HTML allowlist cleaning is for supported HTML fragments; JSON encoding produces JSON literals; JavaScript string escaping also escapes HTML delimiters to prevent closing an inline script. CSS strings and URL components have their own encoders. None makes arbitrary untrusted text safe as executable code, a SQL identifier, HTML attributes or an entire URL. Prefer separate data delivery and parameter binding. SQL-injection-looking user text is legitimate bound data and must not be rejected merely to conceal an unsafe query builder.
