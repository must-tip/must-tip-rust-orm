# v1.0.0 release notes

Lex Framework v1.0.0 establishes the first versioned documentation baseline for the project.

## Included framework areas

- Rust model derive and entity metadata.
- QuerySet and repository persistence APIs.
- PostgreSQL and SQLite support.
- Transactions, concurrency controls, tenant scoping, and PostgreSQL RLS integration.
- Migration engine and CLI workflows.
- REST views, routing, middleware, permissions, authentication, idempotency, throttling, auditing, WebSockets, and Axum adapter.
- Framework-owned session, signed-cookie, and bearer authentication flows.
- Declarative view permissions with scope-based and PostgreSQL database permission backends.
- Secure-input validation/sanitization/encoding pipeline.
- Media storage contracts, filesystem/memory backends, S3-compatible configuration, and ClamAV scanning support.
- Framework settings, CLI scaffolding, project/app creation, verification, and operational commands.
- Production security/operations guidance.

The v1.0.0 label identifies this documentation baseline; the framework can continue improving through the v1 release line.
