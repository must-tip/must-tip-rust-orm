# Versioning

This documentation site is published as **Lex Framework v1.0.0**.

## Version 1 policy

The project is still evolving within the version 1 line. Improvements that remain compatible with the v1 public contract can be published as later v1 releases, for example:

```text
v1.0.1  patch fixes and documentation corrections
v1.1.0  additive framework features
v1.2.0  additional compatible capabilities
```

A future release that intentionally breaks the established public contract should move to a new major version.

## Documentation retention

The website stores documentation in a version-specific namespace. When a later version is added, keep the v1.0.0 pages available so developers can read documentation that matches the framework they have installed.
